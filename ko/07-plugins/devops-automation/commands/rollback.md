# Rollback Deployment

직전의 안정 버전으로 롤백합니다:

1. 이전 배포를 식별
2. 롤백 대상이 정상인지 확인
3. 롤백 절차를 실행
4. 헬스 체크를 실행
5. 팀에 알림
