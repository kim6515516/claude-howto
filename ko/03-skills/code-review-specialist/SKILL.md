# 코드 리뷰 스킬

이 스킬은 다음에 초점을 맞춘 종합적인 코드 리뷰 기능을 제공한다.

1. **보안 분석**
   - 인증·인가 문제
   - 데이터 유출 위험
   - 인젝션 취약점
   - 암호화의 약점
   - 민감 데이터 로깅

2. **성능 리뷰**
   - 알고리즘 효율(Big O 분석)
   - 메모리 최적화
   - 데이터베이스 쿼리 최적화
   - 캐시 기회
   - 동시성 문제

3. **코드 품질**
   - SOLID 원칙
   - 디자인 패턴
   - 명명 규칙
   - 문서
   - 테스트 커버리지

4. **유지보수성**
   - 코드 가독성
   - 함수 크기(50행 미만 권장)
   - 순환 복잡도
   - 의존성 관리
   - 타입 안전성

## 리뷰 템플릿

리뷰한 코드마다 다음을 제공한다.

### 요약
- 전체 품질 평가(1-5)
- 주요 지적 건수
- 권장 우선 영역

### 치명적인 문제(있는 경우)
- **Issue**: 명확한 설명
- **Location**: 파일과 행 번호
- **Impact**: 왜 중요한가
- **Severity**: Critical/High/Medium
- **Fix**: 코드 예시

### 카테고리별 지적 사항

#### 보안(문제가 발견된 경우)
보안 취약점을 예시와 함께 나열

#### 성능(문제가 발견된 경우)
복잡도 분석을 포함해 성능 문제를 나열

#### 품질(문제가 발견된 경우)
리팩터링 제안을 포함해 코드 품질 문제를 나열

#### 유지보수성(문제가 발견된 경우)
개선안을 포함해 유지보수성 문제를 나열
