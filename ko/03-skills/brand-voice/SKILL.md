# 브랜드 보이스 스킬

## 개요
이 스킬은 모든 커뮤니케이션에서 일관된 브랜드 보이스, 톤, 메시지를 유지합니다.

## 브랜드 아이덴티티

### 미션
팀이 AI로 개발 워크플로를 자동화하도록 돕습니다

### 가치
- **단순함**: 복잡한 것을 단순하게 만듭니다
- **신뢰성**: 흔들림 없는 실행
- **임파워먼트**: 사람의 창의성을 끌어냅니다

### 톤 오브 보이스
- **친근하면서도 전문적으로** - 가볍지 않되, 다가가기 쉽게
- **명쾌하고 간결하게** - 전문 용어를 피하고 기술 개념을 알기 쉽게 설명합니다
- **자신감 있게** - 우리가 무엇을 하는지 알고 있습니다
- **공감하며** - 사용자의 필요와 고충을 이해합니다

## 작성 가이드라인

### 해야 할 것 ✅
- 독자를 가리킬 때는 "you"를 사용
- 능동태 사용: "Claude generates reports"라고 쓰고 "Reports are generated by Claude"라고 쓰지 않음
- 가치 제안으로 시작
- 구체적인 예시 사용
- 한 문장을 20단어 미만으로 유지
- 명확성을 위해 목록 사용
- CTA(행동 유도 문구) 포함

### 피해야 할 것 ❌
- 기업 특유의 전문 용어를 쓰지 않음
- 독자를 낮춰 보거나 지나치게 단순화하지 않음
- "we believe"나 "we think"를 쓰지 않음
- 강조 이외에는 전부 대문자로 쓰지 않음
- 글의 벽을 만들지 않음
- 기술적 사전 지식을 전제하지 않음

## 어휘

### ✅ 권장 용어
- Claude ("the Claude AI"가 아님)
- Code generation ("auto-coding"이 아님)
- Agent ("bot"이 아님)
- Streamline ("revolutionize"가 아님)
- Integrate ("synergize"가 아님)

### ❌ 피해야 할 용어
- "Cutting-edge" (진부함)
- "Game-changer" (모호함)
- "Leverage" (기업 용어 느낌)
- "Utilize" ("use"를 사용)
- "Paradigm shift" (불명확함)

## 예시

### ✅ 좋은 예
"Claude automates your code review process. Instead of manually checking each PR, Claude reviews security, performance, and quality—saving your team hours every week."

효과적인 이유: 명확한 가치, 구체적인 이점, 행동 지향적

### ❌ 나쁜 예
"Claude leverages cutting-edge AI to provide comprehensive software development solutions."

효과적이지 않은 이유: 모호함, 기업 전문 용어, 구체적인 가치가 없음
