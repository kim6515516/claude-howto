# 코드 최적화

제시된 코드에 대해 우선순위가 높은 순서로 다음 항목을 검토한다:

1. **성능 병목** — O(n²) 처리나 비효율적인 루프를 찾아낸다
2. **메모리 누수** — 해제되지 않은 리소스나 순환 참조를 발견한다
3. **알고리즘 개선** — 더 나은 알고리즘이나 자료 구조를 제안한다
4. **캐시 가능한 지점** — 반복되는 계산을 찾아낸다
5. **동시성 문제** — 경쟁 상태나 스레딩 문제를 발견한다

답변은 다음 형식으로 정리한다:
- 문제의 심각도(Critical/High/Medium/Low)
- 코드상의 해당 위치
- 설명
- 권장 수정안과 코드 예시
