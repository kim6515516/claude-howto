# 로드맵: claude-howto 2026–2027

> 2026년 4월 ~ 2027년 3월 · 이중 레이어 지식 베이스 | 전체 계획: `TASKS-20260401.md`

---

## 비전

claude-howto를 정적인 튜토리얼 저장소에서 **살아 있는 이중 대상 지식 시스템**으로 전환합니다:

- **사람을 위해** — 시나리오 기반의 인터랙티브 학습. 난이도 단계, 결정 트리, 전문가가 북마크하는 이름 붙은 패턴을 갖춥니다
- **AI 에이전트를 위해** — 에이전트가 Claude Code 작업을 실행하기 전에 조회하는 구조화된 메타데이터 인덱스. 이로써 저장소는 단순한 콘텐츠가 아니라 인프라가 됩니다

AI 에이전트를 주요 대상으로 삼는 경쟁자는 없습니다. 이것이 이 프로젝트의 진입 장벽이 됩니다.

## 마일스톤

### M1 — 인프라 가동 · 2026년 4월 말

**릴리스 내용:**
- `scripts/quickstart.sh` — 신규 사용자를 위한 원커맨드 설정(멱등)
- `QUICKSTART.md` — "첫 15분" 시각 가이드
- 전체 10개 모듈에 난이도 배지와 "What you'll build" 미리 보기
- `WHATS-NEW.md` + 전체 모듈의 버전 배지
- `.github/workflows/staleness-check.yml` — 모듈이 30일 이상 미검증이면 매주 월요일에 이슈 생성
- 루트 `CLAUDE.md` — 프로젝트 자체 설정을 모범 사례 예시로 제시
- `scripts/build-agent-index.py` — 전체 10개 모듈을 읽어 → `agent-manifest.json` + `AGENT-INDEX.md`를 출력하는 생성기
- **06-hooks** — 전면 심화: 완성된 훅 스크립트 5개, 결정 트리, Try It Now, 패턴
- **08-checkpoints** — 전면 심화: 311 → 800줄 이상, 워크플로 템플릿 3개, 결정 트리, 패턴

**여기서 시작하는 이유:** 인프라는 이후 모든 단계에 도움이 됩니다. Hooks와 Checkpoints는 가장 약한 모듈이며, 새 방문자를 가장 놓치기 쉽습니다.
