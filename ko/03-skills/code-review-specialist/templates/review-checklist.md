# 코드 리뷰 체크리스트

## 보안 체크리스트
- [ ] 하드코딩된 인증 정보나 비밀 정보가 없음
- [ ] 모든 사용자 입력에 대한 입력 검증
- [ ] SQL 인젝션 대책(파라미터화 쿼리)
- [ ] 상태를 변경하는 작업에 대한 CSRF 대책
- [ ] 적절한 이스케이프를 통한 XSS 대책
- [ ] 보호된 엔드포인트에서의 인증 확인
- [ ] 리소스에 대한 인가 확인
- [ ] 안전한 비밀번호 해싱(bcrypt, argon2)
- [ ] 로그에 민감한 데이터를 포함하지 않음
- [ ] HTTPS 강제

## 성능 체크리스트
- [ ] N+1 쿼리가 없음
- [ ] 인덱스의 적절한 활용
- [ ] 효과적인 지점에 캐시 구현
- [ ] 메인 스레드에서의 블로킹 작업이 없음
- [ ] async/await의 올바른 사용
- [ ] 대규모 데이터셋의 페이지네이션
- [ ] 데이터베이스 커넥션 풀링
- [ ] 정규 표현식 최적화
- [ ] 불필요한 객체 생성이 없음
- [ ] 메모리 누수 대책

## 품질 체크리스트
- [ ] 함수가 50줄 미만
- [ ] 명확한 변수 이름
- [ ] 중복 코드가 없음
- [ ] 적절한 에러 처리
- [ ] 주석은 "무엇을"이 아니라 "왜"를 설명
- [ ] 프로덕션 환경에 console.log가 없음
- [ ] 타입 검사(TypeScript/JSDoc)
- [ ] SOLID 원칙 준수
- [ ] 디자인 패턴의 올바른 적용
- [ ] 스스로를 설명하는 코드

## 테스트 체크리스트
- [ ] 유닛 테스트 작성
- [ ] 엣지 케이스 커버
- [ ] 에러 시나리오 테스트
- [ ] 통합 테스트 존재
- [ ] 커버리지 80% 이상
- [ ] 불안정한(flaky) 테스트가 없음
- [ ] 외부 의존성 모킹
- [ ] 명확한 테스트 이름
