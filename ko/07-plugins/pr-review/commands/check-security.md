# Security Check

코드 변경에 대해 보안 관점의 분석을 수행한다:

1. 인증 / 인가 점검
2. 데이터 유출 위험
3. 인젝션 취약점
4. 암호 처리의 약점
5. 로그에 포함된 민감 정보
